Week 3 Notes

Core Topic: Web Scraping

This week’s workshop focused on web scraping. Web scraping means automatically gathering information from websites. Instead of manually copying text one‑by‑one, we can use tools to collect large‑scale data.

Key Concept

Web scraping helps researchers collect online content for media‑related research. However, it is not completely unrestricted. We need to consider website rules, copyright and privacy. Some websites block scraping because it may overburden their servers or take their original data.

Workshop Reflection

In this workshop, I tried some simple web‑scraping exercises. At first I thought it would be simple, but I soon noticed many limitations.n principle, web scraping can be acceptable. However, we cannot get hold of the website’s deeper‑level code or encoding. This practice may also lead to copyright‑infringement problems, so we have to be careful.Even if our tool can pull text from a webpage, I still need to check whether I have the right to use that data I also realised there is a big gap between what is technically possible and what is ethically appropriate. Just because we technically can scrape a website, that does not mean we ought to do it. We should respect website terms and protect other people’s personal information. For my digital‑media journal project, web scraping could be a useful method to gather social‑media posts. Still, I would act cautiously. I would only collect publicly available data, avoid users’ private information, and avoid putting too much pressure on the website server. This workshop taught me that data collection is not merely a technical skill; there are also ethical rules we must follow.
